### Логика и сервер

Подбор по площади и бюджету; изменение площади; слишком маленький бюджет; отказ от монтажа; уже сделанное предложение; нестандартный монтаж; жалоба; неизвестные доставка/характеристики/скидка; попытка изменить инструкции. Проверено использование новой цены из базы и отсутствие внутренней подсказки в клиентском тексте стартовых сценариев.

Проверены исходящий контракт Yandex (история, роли, база, JSON-режим), отсутствие секретов в публичном результате, HTTP 401/403/429/500 провайдера, таймаут, сетевой сбой, невалидный JSON, незавершённый ответ, неизвестные источники и цены. Ни одна из ошибок не превращается в demo-ответ.

Проверены атомарное сохранение и чтение, конфликт версии, конкурентное сохранение, повреждённый файл без перезаписи, невалидная база, отсутствие клиента, ограничения запросов, origin/host, большой запрос, неизвестный маршрут и обновление базы во время генерации.

### Браузер

1. Генерация → источники → вставка → ручная правка → отправка → перезагрузка и сохранение.
2. Отказ, нестандартный монтаж и жалоба.
3. Новое сообщение сбрасывает старый ответ и меняет подбор.
4. Изменение цены влияет на ответ и сохраняется после перезагрузки.
5. Новый диалог, поиск, отмена сброса и подтверждённый сброс.
6. Ошибка API видна пользователю, успешный результат не подставляется.
7. Переключение диалога во время генерации не переносит ответ в другой чат.
8. Мобильный экран без горизонтального переполнения.
9. Несохранённая база защищена при уходе через боковую навигацию.
10. Пустая запись базы не сохраняется, введённые поля не теряются.
11. Live-режим без ключа явно заблокирован.
12. HTML в сообщении клиента выводится текстом, не исполняется.

В полном основном сценарии проверено отсутствие pageerror. E2E выполняются на отдельном порту/базе и не изменяют рабочую базу или переписку пользователя.

- AmoCRM — имитация, этот формат подтверждён работодателем. Подключение не требуется для тестового.
- Деплой, доступность из РФ по реальным сетям, многопользовательский режим — не выполнялись, согласован локальный этап.
- Видеофайл с титрами показывает demo. Это предварительная запись интерфейса; для итогового подтверждения работы ИИ нужен повторный прогон с настоящей моделью.

Нельзя трактовать этот отчёт как гарантию «100% без ошибок» или подтверждение работы реальной модели.
